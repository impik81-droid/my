# Мой дневник — Cloudflare
1. Создай Cloudflare Pages проект из этой папки.
2. Создай D1 database и выполни schema.sql.
3. В Pages → Settings → Functions → Bindings привяжи D1 как `DB`.
4. Загрузи проект. API `/api/auth` и `/api/data` будут работать через Pages Functions.
5. Открой сайт, нажми «Войти», создай аккаунт. Данные будут синхронизироваться между устройствами.
